# firmware/atom — AtomS3 ファームウェア

M5Stack AtomS3-Lite + Atomic Echo Base 向けのファームウェアです。  
ボタン操作でホストに問い合わせて AI の返答を再生するほか、ホストが統括する会話の再生や、
ホスト不要の録音再生・オウム返し・タイマーもできます。

この文書は、ファームウェアの設定・書き込み・ログの見方をまとめたものです。
**使い方（ボタン操作・各モードの手順・困ったとき）は [docs/manual.md（操作マニュアル）](../../docs/manual.md)** を参照してください。

> はじめて書き込む場合は、ホストの準備も含めて順番に説明した
> [docs/setup-guide.md](../../docs/setup-guide.md) を参照してください。

## 必要なもの

| ハードウェア | 備考 |
|---|---|
| M5Stack AtomS3-Lite | ESP32-S3 搭載（PSRAM なし・Bluetooth Classic 非対応） |
| Atomic Echo Base | スピーカー・マイク拡張モジュール |
| USB-Cケーブル | データ通信対応のもの |
| Wi-Fi | **2.4GHz 帯**（5GHz 帯には接続できない） |

| ソフトウェア | 備考 |
|---|---|
| [PlatformIO](https://platformio.org/) | VS Code 拡張「PlatformIO IDE」または CLI（`uv tool install platformio`） |

## セットアップ

### 1. .env ファイルを作成する

`.env.template` をコピーして `.env` を作成し、実際の値を入力します。

```bash
cp .env.template .env
```

`.env` を編集します（`.env` は Git に含まれません）。

```
WIFI_SSID=your_wifi_ssid
WIFI_PASSWORD=your_wifi_password
HOST_BASE_URL=http://192.168.1.10:8000
```

→ 各変数の詳細は [環境変数リファレンス](#環境変数リファレンス) を参照してください。

### 2. AtomS3 を PC に接続する

WSL2 環境の場合は [UPLOAD_GUIDE.md](UPLOAD_GUIDE.md) の手順で USB をアタッチしてください。

### 3. ビルド & 書き込み

```bash
# ビルドのみ
~/.platformio/penv/bin/pio run

# 書き込み（シリアルモニターを閉じてから実行）
~/.platformio/penv/bin/pio run --target upload

# シリアルモニターで動作確認
~/.platformio/penv/bin/pio device monitor
```

VS Code の PlatformIO 拡張から実行する場合は、左サイドバーの PlatformIO アイコン →  
`m5stack-atoms3` → **Upload** / **Monitor** を使用してください。

### 4.（任意）モード切替の音声案内を生成する

モード切替時に「チャットモードですわ。」のような音声案内を流せます（声色は参照音声から合成）。
生成しなくてもビルドでき、その場合は従来どおりチャイム音で知らせます。

```bash
# host/ から。既定の参照音声は host/voices/shikoku_metan-normal.wav（各自で配置）
uv run python scripts/generate_mode_prompts.py --wav-dir ../firmware/atom/prompts   # 試聴用 WAV も保存
```

`firmware/atom/include/mode_prompts.h` が生成されるので、その後に通常どおりビルド・書き込みします。
TTS（Irodori-TTS）の環境が必要で、1 文あたり 1〜2 分かかります（全 19 文。2 回目からは変えた文だけ合成します）。案内文は
`host/scripts/generate_mode_prompts.py` の `PROMPTS` で変更できます。

合成済みの案内は次回から再利用されます。1 文だけ作り直すときは `prompts/<配列名>.wav` と `<配列名>.txt` を
消してから再実行します（合成は毎回ゆらぐので、気に入るまで繰り返せます）。語尾が間延びする文面は、同スクリプトの
`DURATION_SCALES` で長さを縮められます（例: 「リレー会話モードですわ。」は 0.85 倍）。

> 参照音声とそこから生成した音声（`mode_prompts.h`・試聴用 WAV）は著作権物を含むため Git 管理外です。
> 四国めたんの声を使う場合はクレジット「VOICEVOX:四国めたん」を表記してください。

## 環境変数リファレンス

`.env` ファイルに設定できる変数の一覧です。  
ビルド時に `load_env.py` が読み込み、ファームウェアにマクロとして埋め込まれます。

| 変数名 | 必須 | デフォルト | 説明 |
|---|---|---|---|
| `WIFI_SSID` | はい | （空） | 接続するWi-FiのSSID（ネットワーク名）。空のままだとWi-Fi接続を試みません。 |
| `WIFI_PASSWORD` | はい | （空） | Wi-Fiのパスワード。オープンネットワークの場合は空にしてください。 |
| `HOST_BASE_URL` | はい | `http://192.168.1.10:8000` | バックエンドAPIサーバーのベースURL。**`http://hostname.local:8000` 形式（mDNS）を推奨** — DHCPでIPが変わっても自動解決されます。ホスト名は `hostname` コマンドで確認できます。IPアドレス直指定も可能です。 |
| `DEVICE_ID` | いいえ | `atoms3-001` | このデバイスの識別子。ホスト側 `device_profiles.json` でこの ID にペルソナ・声色・会話履歴を割り当てます。**複数台で会話させる場合は機体ごとに別の値**（`atoms3-002` 等）にしてください。 |
| `SPEAKER_VOLUME` | いいえ | `100` | 再生音量（0〜255）。音響ループ（voiceモード）でハウリングが出る場合は下げてください。 |
| `PARROT_MIN_RMS` | いいえ | `400` | オウム返しモードが声とみなす音量の下限。静かな部屋で勝手に反応するなら上げ（例 800）、話しても反応しないなら下げる（例 250）。シリアルの `[parrot] rms=… threshold=…` が目安。 |

> **WIFI_SSID が空のまま書き込むと**、AtomS3は暗い紫色に点灯し続けます（設定なし状態）。  
> シリアルモニターに `[wifi] no config` と表示されます。

## 操作方法

**モードは6種類。長押し（1.2秒）で `web → voice → relay → recorder → parrot → timer → web …` と巡回する。**
切替のたびに音声案内（未生成ならチャイム）が流れる。最後に選んだモードは保存され、次回の起動時もそのモードで始まる。
クリックの動作はモードごとに異なる。

| モード（待機 LED） | クリック（短押し） | ダブルクリック | ホスト |
|---|---|---|---|
| **web**（青） | 「こんにちは」を送信して返答音声を再生。再生中なら停止 | － | 必要 |
| **voice**（緑） | 録音 開始 ⇄ 停止（トグル）。停止時に文字起こし結果でチャット | － | 必要 |
| **relay**（シアン） | 再生中なら停止（会話の進行はホストが制御するため通常は操作不要） | － | 必要 |
| **recorder**（白） | 録音 開始 ⇄ 停止（トグル）。再生中なら停止 | 最後の録音を再生 | 不要 |
| **parrot**（黄） | 声の種類を切り替え（高い声 → ふつう → 低い声）。言い返し中なら停止 | － | 不要 |
| **timer**（紫） | 待機中: スタート / 動作中: 中止 / 鳴っている間: 止める | 時間を切り替え（1 → 3 → 5 → 10 → 25 分） | 不要 |

長押し（1.2秒）はどのモードでも次のモードへの切替です。ダブルクリックは、1 回目を離してから 0.5 秒以内に
2 回目を押します。手順を追った説明は [docs/manual.md](../../docs/manual.md) にあります。

> **既知の制限**: web / relay の再生中のクリック停止は、再生の終わり際にしか効きません
> （recorder / parrot の再生は途中で止められます）。

- **web** … ボタンで定型文「こんにちは」を送り、AI の返答を再生する（ホスト必要）。
- **voice** … マイク録音 → STT → LLM → TTS → 自分のスピーカーで再生（手動 PTT。ホスト必要）。
  2 台を空気越しに会話させる「音響ループ」もこのモード（実験的）。
- **relay** … ブラウザから操作する用途（ホスト必要）。ホストに WebSocket 接続して自分の `DEVICE_ID` を
  登録し、ホストから指示された発話を再生する。指示にペルソナが付いていればその声色で鳴らすので、
  **実機 1 台でも 2 体の会話**を再生できる。Web 画面の「実機で会話」「実機に話しかける」で使う
  （→ [setup-guide 5-2](../../docs/setup-guide.md#5-2-ブラウザから操作する)）。
- **recorder** … **ホスト・Wi-Fi 不要の単体動作**。録音はフラッシュ（LittleFS）に保存され、電源を切っても残る。
  1 回ぶん（最大 30 秒、新しく録音すると上書き）。クリックしてから約 0.5 秒後に「ピッ」と鳴って録音が始まり、
  停止時は低い「ピッ」が鳴る。ダブルクリックは、1 回目を離してから 0.5 秒以内に 2 回目を押せば再生になる。
  間が空いて録音が始まってしまっても、0.5 秒未満で止めた録音は捨てて前の録音を残し、そのまま再生する
  （ダブルクリックの失敗で録音を失わない）。録音が無い状態でダブルクリックすると「まだ録音がありませんわ。」と案内する。
- **parrot** … **ホスト・Wi-Fi 不要**のオウム返し。ボタンを押さずに話しかけると、声がした時点から自動で録音し
  （LED が黄色で点滅）、0.7 秒黙ると選んだ声で言い返す（最大 10 秒）。周りの雑音の大きさを自動で学習して
  反応のしきい値を決める。0.3 秒未満の短い音（物音）は無視する。反応しすぎる／しないときは `.env` の
  `PARROT_MIN_RMS` で調整する。声の種類は記憶される。
- **timer** … **ホスト・Wi-Fi 不要**の声で知らせるタイマー。ダブルクリックで時間を選び（声で案内。選んだ時間は
  記憶される）、クリックでスタート。動作中の LED は残り時間で緑 → 黄 → 赤と変わり、1 秒ごとに短く消える。
  2 分以上のタイマーは残り 1 分で「残り1分ですわ。」と知らせ、時間になると「時間ですわ！」を 4 秒ごとに
  繰り返す（クリックで止まる。止めなくても約 30 秒で鳴り止む）。別のモードへ切り替えるとタイマーは中止される。

単体モード（recorder / parrot / timer）の間は、Wi-Fi 再接続・ホストのヘルスチェック・WebSocket を止める
（録音の途切れや反応の遅れを防ぐため）。

## LED カラー

| 色 | 状態 |
|---|---|
| 暗い紫 | `WIFI_SSID` が未設定 |
| オレンジ | Wi-Fi接続中（または未接続） |
| 赤 | Wi-Fi接続済みだがバックエンドに繋がらない |
| 青 | 待機中（webモード、バックエンド正常） |
| 緑 | 待機中（voiceモード、バックエンド正常）／録音中は点滅 |
| シアン | 待機中（relayモード、ホストに接続・登録済み） |
| 白 | 待機中（recorderモード。Wi-Fi・ホストの状態に関係なく白）／録音中は赤で点滅 |
| 黄 | parrot モードで聞き取り中／声を録音中は点滅 |
| 紫 | timer モードの待機中 |
| 緑 → 黄 → 赤（1 秒ごとに短く消える） | タイマー動作中（残り 50% 超 → 20% 超 → それ以下） |
| 赤と白の点滅 | タイマーの時間切れ（アラーム中） |
| マゼンタ | 音声再生中 |
| 起動直後に赤で 5 回点滅 | 直前に電圧低下（brownout）でリセットされた。電源・ケーブルを見直す |
| 起動直後に黄で 5 回点滅 | 直前にファームが異常終了（例外・ウォッチドッグ）してリセットされた |

## トラブルシューティング

**シリアルモニターに何も出ない**  
→ シリアルモニターを開いた状態でAtomS3をリセットしてください（USB CDC接続待機があるため、起動後に開くとログを見逃します）。
接続待機（最大 5 秒）は PC につないでいるときだけで、充電器・モバイルバッテリー給電ではすぐ起動します。

**PC から外して USB 給電だけで動かすと調子が悪い**  
→ 症状で切り分けます。
- **LED が消えて無反応になる** … モバイルバッテリーの自動オフ（消費電流が小さいと数十秒〜数分で給電を止める
  機種が多い）。単体モードは Wi-Fi を使わず消費が小さいので起きやすい。USB 充電器か、低電流モード付きの
  モバイルバッテリーを使う。
- **勝手に再起動する（案内音声がもう一度流れる）** … 起動直後に LED が赤で 5 回点滅するなら電圧低下。
  ケーブルを短く太いものに替える、`SPEAKER_VOLUME` を下げる。黄で点滅するならファームの異常終了なので、
  PC につないでシリアルログを確認する。
- **LED が赤／オレンジでボタンの効きが悪い** … web / voice / relay モードでホスト PC に届いていない。
  ホストを起動するか、長押しで単体モード（recorder / parrot / timer）へ切り替える。届かない間も
  30 秒ごとに最大 1.5 秒だけホストを確認するので、その瞬間の短いクリックは取りこぼすことがある。

**`[wifi] no config` と表示される**  
→ `.env` ファイルに `WIFI_SSID` が設定されているか確認してください。

**`[health] ... -> -1` または赤点灯**  
→ `HOST_BASE_URL` のIPアドレスとポートが正しいか、バックエンドサーバーが起動しているか確認してください。

**アップロードが失敗する**  
→ シリアルモニターを閉じてから再試行してください。それでも失敗する場合は、側面のリセットボタンを約 2 秒
長押しして書き込みモード（内部の緑 LED が点灯）にしてから Upload します。充電専用ケーブルでないかも確認して
ください。WSL2 の場合は [UPLOAD_GUIDE.md](UPLOAD_GUIDE.md) を参照してください。

**モード切替の案内が音声でなくチャイムになる**  
→ `include/mode_prompts.h` が未生成です（任意機能）。「4.（任意）モード切替の音声案内を生成する」の手順で
生成してから書き込み直してください。

**録音再生モードで録音できない（エラー音）**  
→ 初回起動時のフラッシュのフォーマットに失敗している可能性があります。シリアルログの `[boot] LittleFS:` が
`ng` なら、`pio run --target erase` で消去してから書き込み直してください（保存済みの録音とモード記憶も消えます）。
