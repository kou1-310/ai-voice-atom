# 話者リファレンス音声の置き場所

ここに `reference.wav` を置くと、TTS（Irodori-TTS）がその声色を真似て音声合成する。
ファイルが無ければ既定の声で合成する（特別な設定は不要）。

- 既定のパス: `host/voices/reference.wav`
- 別の場所を使う場合は環境変数 `AI_VOICE_ATOM_TTS_REF_WAV` でパスを指定する
  （相対パスはリポジトリルート基準）。

## 推奨フォーマット

- 単一話者・クリーンな音声（無音/雑音が少ないもの）
- 数秒〜30秒程度（30秒を超える分は自動で切り詰められる）
- 形式は wav。サンプルレートは問わない（内部でリサンプルされる）。

ファイルは実行のたびに存在確認するので、差し替えにサーバー再起動は不要。
常駐 TTS サイドカー経路でもこのリファレンスを使って合成する。

## モード切替の音声案内

`host/scripts/generate_mode_prompts.py` は、既定でこのフォルダの `shikoku_metan-normal.wav` を声色の参照に使います
（`--ref-wav` で変更可）。ここに置いた音声とそこから生成した音声は Git に含めません。
他人の声やキャラクター音声を使う場合は、その利用規約に従ってください（例: VOICEVOX の四国めたんは「VOICEVOX:四国めたん」のクレジット表記が必要）。
