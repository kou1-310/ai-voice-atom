現在の変更（`git diff` と `git diff --staged`、必要なら `git diff main...HEAD`）を一次レビューする。`docs/ai-native-rules.md` 第1章の Constitution を中心に、**確信度の高い指摘のみ**を挙げる（ノイズを出さない）。

## 点検リスト

- **音声フォーマット不変条件**: デバイス経路の WAV が 16kHz/mono/16-bit を維持しているか。`utils/wav.py::to_pcm16_mono` を迂回していないか。
- **エラー契約**: バックエンド利用不可/失敗→`RuntimeError`、不正入力→`ValueError`。ルーターが 503/400 へマップする構造を崩していないか。新規の例外がこの体系から外れていないか。
- **設定**: 新しい設定が `AI_VOICE_ATOM_` 環境変数 + 標準ライブラリ解析で実装されているか。**外部設定ライブラリを足していないか。** `config.py` が既存 env を上書きしない原則を守っているか。
- **マルチデバイス**: 履歴キーが `device_id::session_id` 複合のままか。未登録 device_id がグローバル設定へフォールバックするか（プロファイル必須化していないか）。
- **テスト**: 変更にひも付く再現/受け入れテストがあるか。フェイクは**コンストラクタ注入**か（環境変数依存・実 GPU/TTS/STT 起動になっていないか）。
- **言語**: 追加コメント・docs・ユーザー向け文言が日本語か。Python が 3.11+ 型ヒント付きか。
- **セキュリティ**: 外部入力（base64 PCM、ヘッダ、JSON）をバリデーションしているか。サブプロセス引数にユーザー入力を素通しでシェル展開していないか。秘密情報（.env/APIキー）をコミットしていないか。
- **ドキュメント整合**: 挙動を変えたなら `docs/` / `CLAUDE.md` の該当記述を更新したか（食い違う場合はコードが正）。

## 出力

- 重大度（高/中/低）つきで指摘を列挙。各指摘に `file:line` と修正案を添える。
- 指摘ゼロなら明言する。
- 繰り返し型の指摘（同種の誤りが2回目）は `docs/templates/lessons-learned.md` への追記を提案する。
