## 1. 基本の操作

AtomS3-Lite は**上面全体が 1 つのボタン**です。操作は次の 3 種類だけです。

| 操作 | やり方 | 働き |
|---|---|---|
| **クリック** | 短く押して離す | モードごとの主な操作（録音の開始・停止など） |
| **ダブルクリック** | クリックを 2 回続ける。1 回目を離してから **0.5 秒以内**に 2 回目を押す | 録音再生モードの**再生**、タイマーの時間切替 |
| **長押し** | **1.2 秒以上**押し続ける | **次のモードへ切り替える** |

- 長押しのたびに、モードは次の順に切り替わります。切り替わると声（または音）でモード名を案内します。

  ```
  チャット → 音声会話 → リレー会話 → 録音再生 → オウム返し → タイマー → （チャットへ戻る）
  ```

- 最後に選んだモードは記憶されます。電源を入れ直すと、同じモードで始まります。
- 電源を入れると、約 1〜2 秒後に今のモード名を案内します。これが起動完了の合図です。
- 録音中（LED が点滅しているあいだ）の長押しは、モード切替にならず録音の停止になります。

## 2. モード早見表

| モード | 待機中の LED | クリック | ダブルクリック | ホスト PC |
|---|---|---|---|---|
| **チャット**（web） | 青 | 「こんにちは」と話しかけ、AI の返事を再生 | － | 必要 |
| **音声会話**（voice） | 緑 | 録音開始 → もう一度押すと停止し、AI が返事 | － | 必要 |
| **リレー会話**（relay） | シアン | －（ブラウザから操作する） | － | 必要 |
| **録音再生**（recorder） | 白 | 録音開始 → もう一度押すと停止 | **録音を再生** | 不要 |
| **オウム返し**（parrot） | 黄 | 声の種類を切り替え | － | 不要 |
| **タイマー**（timer） | 紫 | スタート／中止／アラームを止める | 時間を切り替え | 不要 |

「ホスト PC 必要」のモードは、ホストのサーバーが動いていて、同じ Wi-Fi につながっているときに使えます。
「不要」の 3 モードは、Wi-Fi もホストも無い場所で単体で動きます。

## 3. ホストを使うモード

待機中の LED がモードの色（青・緑・シアン）になっていれば準備完了です。
**オレンジ**なら Wi-Fi に接続中、**赤**ならホストに届いていません（[10. 困ったとき](#10-困ったとき)）。

返事の音声は、AI が文章を考えて声にするまで 10〜30 秒ほどかかります（GPU の有無や文の長さで変わります）。
待っているあいだ LED はオレンジ、再生中はマゼンタになります。

### チャット（web）— LED 青

決まった一言「こんにちは」を AI に送り、返事を聞くモードです。動作確認にも使えます。

1. クリックします。LED がオレンジになります。
2. 返事ができると LED がマゼンタになり、キャラクターの声で再生されます。
3. 再生が終わると青に戻ります。

### 音声会話（voice）— LED 緑

自分の声で話しかけ、AI の返事を聞くモードです。

1. クリックします。LED が**緑の点滅**になったら録音中です。
2. マイク（本体下の Echo Base）に向かって話します。
3. もう一度クリックして録音を止めます。LED がオレンジになり、文字起こし → 返事の作成 → 音声合成が進みます。
4. LED がマゼンタになり、返事が再生されます。

- 何も聞き取れなかったときは、返事をせずに緑へ戻ります。近くではっきり話してください。
- 低い音が 3 回鳴ったら失敗です。ホストに届いていないか、音声認識の準備ができていません。

### リレー会話（relay）— LED シアン

ブラウザの Web 画面から操作するモードです。実機は、ホストから指示されたセリフを再生する役です。

- 2 体のキャラクターを交互に話させる（実機 2 台に分ける、または 1 台で両方の声を出す）
- Web 画面に入力した言葉に、キャラクターが実機の声で答える

実機側の操作はありません。長押しでこのモードにして、LED がシアンになるのを待ってから、
[5. Web 画面の使い方](#5-web-画面の使い方) の手順で始めます。

> **再生を途中で止めたいとき**: チャットとリレー会話では、再生中のクリックは再生の終わり際にしか効きません
> （既知の制限）。リレー会話は Web 画面の「停止」で止められます。

## 4. 単体で使えるモード

### 録音再生（recorder）— LED 白

最大 30 秒の音を録って、あとで聞き直せます。録音は電源を切っても残ります。

**録音する**

1. クリックします。約 0.5 秒後に「ピッ」と鳴り、LED が**赤の点滅**になります。ここから録音されます。
2. 話します。
3. もう一度クリックします。低い「ピッ」が鳴って保存され、LED が白に戻ります。

**再生する**

- **ダブルクリック**します。LED がマゼンタになり、録音が再生されます。
- 再生中にクリックすると止まります。

**知っておくと便利なこと**

- 録音は 1 つだけです。新しく録音すると前の録音は置き換わります。
- 30 秒たつと自動で止まって保存されます。
- 録音が無いときにダブルクリックすると「まだ録音がありませんわ。」と案内します。
- ダブルクリックが遅くて「ピッ」と鳴ってしまっても、前の録音は消えません。0.5 秒未満で止めた録音は捨てて、
  前の録音をそのまま再生します。

### オウム返し（parrot）— LED 黄

話しかけると、変な声で言い返します。ボタンは押しません。

1. 本体に向かって話します。声を検出すると LED が**黄の点滅**になり、自動で録音します。
2. 0.7 秒ほど黙ると、言い終わりとみなして言い返します（LED マゼンタ）。
3. 言い返したあと、また聞き取りに戻ります。

- **クリック**すると声の種類が「高い声 → ふつう → 低い声」の順に切り替わり、声で案内します。選んだ声は記憶されます。
- 言い返している最中にクリックすると、言い返しを止めます。
- 一度に録れるのは 10 秒までです。0.3 秒未満の短い音（物音）は無視します。
- まわりの雑音の大きさを自動で学習し、それより十分大きい音を声とみなします。
  勝手に言い返す、または反応しないときは、`PARROT_MIN_RMS` を調整します（[9. 設定を変える](#9-設定を変える)）。

### タイマー（timer）— LED 紫

時間になると声で知らせるタイマーです。

1. **ダブルクリック**で時間を選びます。押すたびに「1 → 3 → 5 → 10 → 25 分」と切り替わり、声で案内します。
   選んだ時間は記憶されます（はじめは 3 分）。
2. **クリック**でスタートします（「スタートですわ。」）。
3. 時間になると「時間ですわ！」を 4 秒ごとに繰り返します。**クリック**で止まります
   （止めなくても約 30 秒で鳴り止みます）。

- 動作中の LED は残り時間を表します。半分より多ければ緑、2 割より多ければ黄、それ以下は赤です。
  動いている目印として、1 秒ごとに一瞬消えます。
- 2 分以上のタイマーは、残り 1 分で「残り 1 分ですわ。」と知らせます。
- 動作中にクリックすると中止します（「タイマーを止めましたわ。」）。
- 別のモードへ切り替えると、タイマーは中止されます。

## 5. Web 画面の使い方

ホストのサーバーを動かしている PC、または同じ Wi-Fi のスマホ・PC のブラウザで、次を開きます。

```
http://<ホスト PC の IP アドレス>:8000/frontend/
```

画面右上の「LLM / TTS / STT」が「稼働」になっていれば、ホストの準備はできています。

画面上部の**実行モード**で、やりたいことを選びます。

| 実行モード | できること | 必要な実機 |
|---|---|---|
| **画面でデモ** | 2 体のキャラクターの会話を、ブラウザで再生する | なし |
| **実機で会話** | 2 体の会話を実機で再生する | 1 台または 2 台 |
| **実機に話しかける** | 入力した言葉にキャラクターが答え、実機がその声で話す | 1 台 |

### 画面でデモ

1. 「ペルソナ A」「ペルソナ B」でキャラクターを選びます。
2. 「話題（最初の一言）」を入れ、「ターン数」（2〜20）を決めます。
3. 「デモを再生する」を押します。2 体が交互に話し、ブラウザから声が出ます。「停止」で止まります。

### 実機で会話

1. 使う AtomS3 を長押しで**リレー会話モード（LED シアン）**にします。
   画面に「接続中の実機: atoms3-001」のように表示されるのを待ちます。
2. キャラクター 2 体と話題、ターン数を決めます。
3. 「スピーカー（実機）」を選びます。
   - **各ペルソナの実機（2 台）**: キャラクターごとに別の実機が話します。
   - **実機 1 台**を選ぶ: 1 台が 2 体ぶんの声を出し分けます。
4. 「実機で会話をはじめる」を押します。実機が 1 ターン話し終えるのを待って、次のターンへ進みます。

### 実機に話しかける

1. AtomS3 をリレー会話モード（LED シアン）にします。
2. 答えるキャラクターと、声を出す実機を選びます。
3. 「話しかける言葉」を入れて「話しかける」を押します。実機が答え終わると、返事の文章が画面に出ます。

ページを開いているあいだは、会話の流れを覚えています。

## 6. LED の色

| 色 | 意味 |
|---|---|
| 青 | チャットモードで待機中 |
| 緑 | 音声会話モードで待機中（**点滅**は録音中） |
| シアン | リレー会話モードで待機中 |
| 白 | 録音再生モードで待機中（**赤の点滅**は録音中） |
| 黄 | オウム返しモードで聞き取り中（**点滅**は声を録音中） |
| 紫 | タイマーモードで待機中 |
| 緑 → 黄 → 赤（1 秒ごとに一瞬消える） | タイマー動作中（残り時間が減るほど赤に近づく） |
| 赤と白の点滅 | タイマーの時間切れ（アラーム中） |
| マゼンタ | 音声を再生中 |
| オレンジ | Wi-Fi に接続中、または返事を待っている |
| 赤 | Wi-Fi にはつながったが、ホストに届かない |
| 暗い紫 | Wi-Fi の設定（`WIFI_SSID`）が書き込まれていない |
| 起動直後に赤で 5 回点滅 | 直前に電圧不足でリセットされた（電源・ケーブルを見直す） |
| 起動直後に黄で 5 回点滅 | 直前にファームが異常終了してリセットされた |

白・黄・紫（単体モード）は、Wi-Fi やホストの状態に関係なくその色になります。

## 7. 音の意味

| 音 | 意味 |
|---|---|
| 「〇〇モードですわ。」 | モードが切り替わった／起動した |
| 高い「ピッ」 | 録音再生モードの録音開始 |
| 低い「ピッ」 | 録音再生モードの録音停止（保存） |
| 低い音が 3 回 | 失敗（ホストに届かない、マイクを起動できない、保存先を使えない、など） |

音声案内は任意の機能です。案内を作らずに書き込んだ場合は、モードごとに違うチャイムで知らせます
（作り方は [firmware/atom/README.md](../firmware/atom/README.md) の「モード切替の音声案内を生成する」）。

| モード | 案内が無いときのチャイム |
|---|---|
| チャット | 低い音 1 回 |
| 音声会話 | 上がる 2 音 |
| リレー会話 | 上がる 3 音 |
| 録音再生 | 下がる 2 音 |
| オウム返し | 高く短い音 3 回 |
| タイマー | 同じ高さの音 2 回 |

## 8. 電源と持ち運び

- USB Type-C で給電します。PC につながなくても、USB 充電器やモバイルバッテリーで動きます。
- 電源を入れると、前回のモードですぐに始まります。単体モードなら Wi-Fi もホストも要りません。
- **モバイルバッテリーは自動で電源が切れることがあります。** 消費電流が小さいと数十秒〜数分で給電を止める機種が
  多く、単体モードは消費が小さいので起きやすくなります。LED が消えて反応しなくなったらこれが原因です。
  USB 充電器か、低電流モードのあるモバイルバッテリーを使ってください。
- ホスト PC の電源を切ったままチャット・音声会話・リレー会話モードにすると、LED が赤になります。
  その場合は長押しで単体モードへ切り替えてください。

## 9. 設定を変える

デバイスの設定は `firmware/atom/.env` に書き、**書き込み直すと反映**されます
（書き込み方は [setup-guide.md の 4 章](setup-guide.md#4-atoms3-にファームウェアを書き込む)）。

| 変えたいこと | 項目 | 目安 |
|---|---|---|
| 音量 | `SPEAKER_VOLUME`（0〜255、既定 100） | 小さくするなら 60、大きくするなら 160 |
| オウム返しの反応しやすさ | `PARROT_MIN_RMS`（既定 400） | 勝手に言い返すなら 800、反応しないなら 250 |
| つなぐ Wi-Fi・ホスト | `WIFI_SSID` / `WIFI_PASSWORD` / `HOST_BASE_URL` | |
| どのキャラクターか | `DEVICE_ID`（既定 `atoms3-001`） | 複数台を使うときは 1 台ずつ変える |

キャラクターの性格・口調・声は、ホスト側の `host/device_profiles.json` で決めます。
書き方は [host/README.md](../host/README.md) の「ペルソナ定義」を参照してください（変更後はサーバーを再起動します）。

## 10. 困ったとき

| 症状 | 原因と対処 |
|---|---|
| **録音再生モードでクリックしても再生されない** | 再生は**ダブルクリック**です。クリック 1 回は録音開始になります |
| ダブルクリックしたのに「ピッ」と鳴って録音が始まる | 2 回のクリックの間が空きすぎています。すぐにクリックして止めれば、前の録音は消えずに再生されます |
| LED が赤のまま | ホストに届いていません。ホストのサーバーが動いているか、`HOST_BASE_URL` の IP が合っているか、PC の IP が変わっていないかを確認します |
| LED がオレンジのまま | Wi-Fi につながっていません。SSID・パスワード、2.4GHz 帯の Wi-Fi かどうかを確認します |
| LED が暗い紫 | Wi-Fi の設定が書き込まれていません。`firmware/atom/.env` を作って書き込み直します |
| クリックすると低い音が 3 回鳴る | ホストに届かないか、ホスト側で失敗しています。サーバーのログを確認します |
| 返事が遅い | AI の処理に時間がかかっています。[performance-tuning.md](performance-tuning.md) を参照します |
| LED が消えて反応しない | モバイルバッテリーの自動オフです（[8. 電源と持ち運び](#8-電源と持ち運び)） |
| 勝手に再起動する（案内がもう一度流れる） | 起動時に LED が赤で 5 回点滅するなら電圧不足です。ケーブルを短く太いものに替えるか、音量を下げます |
| オウム返しが勝手に言い返す／反応しない | `PARROT_MIN_RMS` を上げる／下げる（[9. 設定を変える](#9-設定を変える)） |
| 音声会話で聞き取ってくれない | マイクに近づいてはっきり話します。直らなければホスト側の音声認識の準備を確認します（[setup-guide.md の 7 章](setup-guide.md#7-困ったとき)） |
| 声がキャラクターごとに変わらない | `device_profiles.json` の `ref_wav` のファイルがあるか確認し、サーバーを再起動します |
| Web 画面に実機が表示されない | 実機がリレー会話モード（シアン）になっているか確認します |
| モードの案内が声ではなくチャイムになる | 音声案内を作らずに書き込んでいます（任意の機能）。[7. 音の意味](#7-音の意味) を参照します |

これで解決しないときは、原因を順番に切り分ける [verification-guide.md](verification-guide.md)（動作確認手順書）を使ってください。
