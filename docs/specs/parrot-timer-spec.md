# Spec: 単体モードの追加 — オウム返し（parrot）とタイマー（timer）

> `docs/ai-native-rules.md` 第1章に従う。2026-09-23 作成。関連: `docs/specs/mode-guidance-recorder-spec.md`。

## Outcomes（成功の定義 / ユーザー・デバイス視点）

- ホスト・Wi-Fi なしで、話しかけると AtomS3 が自動で聞き取り、変な声で言い返す（ボタン操作不要）。
- ホスト・Wi-Fi なしで、声で知らせるタイマーとして使える（時間を選ぶ → スタート → 残り時間を LED で確認 → 時間になると声で知らせる）。

## Scope（範囲境界）

- やること:
  - ファームに `parrot` / `timer` モードを追加。巡回は `web → voice → relay → recorder → parrot → timer → web`。
  - 案内音声を追加（モード名、声の種類、タイマーの時間・開始・中止・残り 1 分・終了）。
  - `generate_mode_prompts.py` に、合成済みの文を再利用する仕組みと、ヘッダの版数を追加。
- やらないこと: 音声認識（デバイス上では PSRAM 不足で不可）、ロボット声などの信号処理エフェクト、
  モードをまたいだタイマーの継続、複数タイマー。
- 触ってよいファイル: `firmware/atom/src/main.cpp`, `firmware/atom/load_env.py`, `firmware/atom/.env.template`,
  `host/scripts/generate_mode_prompts.py`, `host/tests/test_generate_mode_prompts.py`, 関連ドキュメント。
- 触ってはいけない: ホスト API、`utils/wav.py` の出力フォーマット。

## Constraints

- マイクとスピーカーは I2S を共有し同時に使えない（聞く → 止めて再生 → 再び聞く、を切り替える）。
- RAM 約 320KB・PSRAM なし。オウム返しの録音は RAM に溜めず LittleFS（`/parrot.pcm`、最大 10 秒）へ書く。
- 単体モード（recorder / parrot / timer）の間は Wi-Fi 再接続・ヘルスチェック・WebSocket を行わない。
- 案内音声のヘッダが古い（版数が足りない）場合も、ビルドが通りチャイムで代用すること。

## Prior decisions

- 2 つとも独立したモードにする（ユーザー決定 2026-09-23）。
- 声の変化は再生サンプルレートの変更で実現する（高い声 = 速く高く、低い声 = 遅く低く）。軽くて確実なため。
- 発話検出は音量（100ms ごとの RMS）で行い、しきい値は雑音レベルの自動推定 × 係数と下限値の大きい方。
  下限値は `.env` の `PARROT_MIN_RMS` で調整できる（マイク感度・環境差のため）。
- タイマーの操作: クリック = 開始 / 中止 / 鳴動停止、ダブルクリック = 時間の切替（待機中のみ）。

## Requirements（EARS）

- parrot モードである間、システムはマイクで聞き続け、音量がしきい値を超えたら直前 0.2 秒を含めて録音を始めなければならない。
- 録音中に 0.7 秒以上静かになったとき、または 10 秒に達したとき、システムは録音を止め、選択中の声で再生しなければならない。
- 有音が 0.3 秒未満の録音は、雑音とみなして再生せず破棄しなければならない。
- 再生のあと、システムは 0.3 秒待ってから聞き取りを再開しなければならない（自分の声の拾い込み防止）。
- parrot モードでクリックしたとき、システムは声の種類を「高い声 → ふつう → 低い声」の順に切り替えて案内しなければならない。
- timer モードの待機中にダブルクリックしたとき、システムは時間を 1 / 3 / 5 / 10 / 25 分の順に切り替えて案内しなければならない。
- timer モードの待機中にクリックしたとき、システムはタイマーを開始しなければならない。動作中のクリックでは中止しなければならない。
- タイマーの残りが 1 分になったとき（2 分以上のタイマーのみ）、システムは「残り1分ですわ。」と案内しなければならない。
- タイマーが 0 になったとき、システムは「時間ですわ！」を一定間隔で繰り返し、クリックまたは上限回数で止めなければならない。
- 声の種類とタイマーの時間は NVS に保存し、次回起動時に復元しなければならない。
- 生成スクリプトは、試聴用 WAV とその文面が一致する案内を再合成せずに再利用しなければならない。

## Verification criteria

- [ ] `uv run pytest` 全パス（再利用ロジックのテストを含む）、ruff クリーン
- [ ] `pio run` がヘッダ有り（新版）・無し・旧版の 3 通りでビルド成功
- [ ] 実機（人間）: オウム返しが静かな部屋で誤反応せず、話すと言い返す。声の種類が切り替わる
- [ ] 実機（人間）: タイマーの時間切替・開始・中止・残り 1 分・終了の案内と LED
